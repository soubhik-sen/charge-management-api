# LedgerFlow Web

Responsive Flutter reference client for the LedgerFlow charge-management API.

```bash
flutter pub get
flutter run -d chrome --dart-define=LEDGERFLOW_API_URL=http://localhost:8000
```

The application starts with demo data. Use **Connect API** to supply a live API URL and bearer token. See [`../../docs/web-application.md`](../../docs/web-application.md) for module and deployment guidance.
